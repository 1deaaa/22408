## 解答题

### 第 15 题（10 分）

已知函数$f(x) = \begin{cases}
     x^{2x}, & x > 0, \\
  x\mathrm{e}^x + 1, & x \le 0.
\end{cases}$求$f'(x)$，并求函数$f(x)$的极值．

### 第 16 题（10 分）

求不定积分$\int \frac{3x + 6}{(x - 1)^2(x^2 + x + 1)}\,\mathrm{d}x$．

### 第 17 题（10 分）

设函数$y(x)$是微分方程$y'-xy=\frac{1}{2\sqrt{x}}\mathrm{e}^{\frac{x^2}{2}}$满足条件$y(1)=\sqrt{\mathrm{e}}$的特解．

（1）求$y(x)$的表达式；

（2）设平面区域$D = \{(x,y)|1 \le x \le 2,0 \le y \le y(x)\}$，
      求$D$绕$x$轴旋转一周所形成的旋转体的体积．

### 第 18 题（10 分）

设平面区域$D = \left\{(x,y)\middle||x| \le y, (x^2 + y^2)^3 \le y^4\right\}$，
计算二重积分$$\iint_D \frac{x + y}{\sqrt{x^2 + y^2}}\,\mathrm{d}x\,\mathrm{d}y.$$

### 第 19 题（10 分）

设$n$是正整数，记$S_n$为曲线$y = \mathrm{e}^{- x}\sin x$（$0 \le x \le n\pi$）
与$x$轴所围成图形的面积，求$S_n$，并求$\lim_{n \to \infty} S_n$．

### 第 20 题（11 分）

已知函数$u(x,y)$满足关系式
$2\frac{\partial^2 u}{\partial x^2} - 2\frac{\partial^2 u}{\partial y^2} + 3\frac{\partial u}{\partial x} + 3\frac{\partial u}{\partial y} = 0$．
求$a$, $b$的值，使得在变换$u(x,y) = v(x,y) \mathrm{e}^{ax + by}$之下，
上述等式可化为函数$v(x,y)$的不含一阶偏导数的等式．

### 第 21 题（11 分）

已知函数$f(x)$在$[0,1]$上具有二阶导数，且
$$f(0) = 0,\quad f(1) = 1,\quad \int_0^1 f(x)\,\mathrm{d}x = 1.$$
证明：

（1）存在$\xi \in(0,1)$，使得$f'(\xi) = 0$；

（2）存在$\eta \in(0,1)$，使得$f''(\eta) < - 2$．
